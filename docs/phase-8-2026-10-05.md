# Phase 8 (Analytics) — closed 2026-10-05

Analytics is a key selling point, so every board was rebuilt card for card against the approved canvas
(https://claude.ai/artifact/6X1u5VivMqy438qemCsPRH), in Porcelain and Obsidian, on a realistic demo business,
and checked beside the canvas renders in `docs/design/phase8/screens/`.

## What's in it

- **Engine (8A–8D-1):** rollups with dirty-day recounts, sealed drill tokens (every number opens its leads),
  people/team/source/tag/field filters, revenue, lost matrix, segments, team, timing + meetings, quality, the rep's
  own numbers, CSV export, 14 insight detectors with cooldowns, goals with pace, source spend, the Monday email.
- **Boards (8D-2):** Overview (per-tile daily sparklines from the tiles' own definitions), Funnel, Team, Revenue &
  sources, Lost, Timing & meetings, Templates & data, and the rep's My numbers / My funnel / My timing. Filters panel
  + chips in the address; Export for those who may export; Refresh recounts.
- **Screens (8D-3):** Settings → Goals, Settings → Sources & spend, Log a call in the lead drawer (C).
- **A guard:** no insight or preview ever assumes a person's gender (`packages/core/src/analytics/pronouns.test.ts`).

## Real bugs found on the way (each fixed with a test that failed first)

- What converts and the demo seed used the wrong select-option shape: every group showed a raw id.
- `money()` ignored the spec's lakh/crore for rupees (₹58.4L, ₹6.2Cr).
- An analytics error never cleared and its board loaded forever; now per board, cleared with the range, Try again.
- Goals editor: a save in flight could reload the old period (and then delete the wrong goal); a reload wiped boxes
  being typed in. Goals were counted with hundreds of sequential queries; now three grouped reads.
- Quality told viewers who don't see the whole business "every lead has someone".
- Filters offered people outside the viewer's reach (every board then refused) and couldn't pick the default pipeline.
- Log a call measured "first contact" from when an imported lead entered LUME, not its enquiry date.
- Today's reply-rate line counted days with nobody contacted as 0%.
- The won-back flow was always 0 in production (8D-1, a reopen clears lost_at).

## Rulings (decisions taken on the owner's behalf, each with its cost if wrong)

- "Clear read" hides read notifications (cleared_at) rather than deleting — Undo possible, the worker's sweep removes read ones later anyway — cost if wrong: none.
- Compare toggle built as the canvas's green switch (owner first said "classic blue toggle", then sent the canvas showing green) — cost if wrong: one colour token.
- Settings search opens the setting's page and lights the first heading/label naming it (generic finder, no per-page anchors) — cost if wrong: a setting whose label differs isn't lit, the page still opens.
- bell rings on load + every 30 s while unread and the tab is visible, never with sound — owner asked it to "animate like it's ringing when it has notifications unread" — cost if wrong: an interval constant.
- Today's quick stats are the canvas/prototype's four (new leads, reply rate, calls booked: 7 days vs 7 before; revenue won: this month vs last), at the viewer's analytics reach — cost if wrong: which four.
- tasks.test "done … says when the day is clear" was clock-flaky (12-hour guess on the real clock vs the API's harness clock); now computed on the API's clock and day — cost if wrong: none.
- docs/design/** ignored by eslint (canvas sources copied in from scratch for 8D-2/8D-3/Phase 9 reference) — cost if wrong: none.
- e2e "no Refresh anywhere without Sheets" rewritten to "Refresh still reloads the list and never syncs a sheet" — the owner asked for Refresh on Leads/Pipeline always — cost if wrong: none.
- the Analytics address accepts only UUID lists for owner/team/source/tag/pipeline and a {key:[string]} object for fields; anything else is dropped silently — a hand-edited link must never break a board — cost if wrong: a non-UUID id would be ignored (none exist).
- "Early days." headline under 30 leads in range (EARLY_DAYS = 30) so trends don't oversell a thin month — cost if wrong: one constant.
- "right now" tiles (Follow-ups overdue, Pipeline forecast) and the cycle have no sparkline — there is no honest daily history for them; the canvas drew one on every tile — cost if wrong: a snapshot history table later.
- under a tag or field filter (live reads) only New leads and Won get sparklines — a live read per day per tile would be too slow at scale — cost if wrong: blank lines under filters.
- the canvas's "Last 14 days" per-person sparkline column is left out — there's no per-person daily series yet, and a made-up line would be dishonest — cost if wrong: one more API read per person.
- speed-to-lead colour in the table is relative to the team's own median (<=0.75x good, >=1.5x slow; only with 3+ people) instead of the canvas's fixed 12/25 min — businesses differ — cost if wrong: two constants.
- return on spend reads "4.2×" (not currency) and colours hi ≥3×, lo <1× (losing money), else neutral — the canvas's 8/3 thresholds were for its INR mock — cost if wrong: two constants.
- "Add spend" links to /settings/sources (the approved Sources & spend board, built in 8D-3) — must exist before deploy.
- Timing has no "Time in each stage" table now — the canvas puts it on Funnel, where it already is — cost if wrong: re-add a card.
- no "Booked, then won" meeting tile — the API doesn't count it yet; four honest tiles instead of five — cost if wrong: one query.
- tab stays "Timing" (not "Timing & meetings") so the bar fits one line at 1440 — cost if wrong: a label.
- below 1500px the Analytics Refresh shows only its arrow (label kept for screen readers/tooltip) so the bar fits one line at 1440; at 1366 the control group wraps whole, right-aligned — cost if wrong: CSS.
- popovers that open from a button in the drawer's right half align to the button's end (the LogCall canvas mock ran off the window) — cost if wrong: one prop.
- below 1500px the range button hides "vs the 30 before" (still in the popover and on each number's chip) so the bar fits one line at 1440 — cost if wrong: CSS.
- Timing opens on Arrivals when a business logs no replies, Replies otherwise — cost if wrong: default view.
- #12 (part) spend amounts stay visible to settings.manage without analytics.revenue — they're the amounts that admin types; revenue-derived figures stay gated — cost if wrong: hide two columns.
