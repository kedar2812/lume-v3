# Which number a run sends from (design, approved 2026-11-26)

**Owner, 2026-11-26:** "both lume and lume ai will ask before starting any sort of run, which number will be used to
send these messages, and only then it will begin these runs ... showcase the differentiation ... which number has
which leads contacted, maybe add a filter ... keep it simple". Approved as proposed ("yes").

## Asking before a run starts

- The focus run's Start popover and LUME AI's start sheet show **Send from**.
- One number the person can use: stated ("Sends from +91 97642 56655 · the business's"); nothing to pick.
- Two or more: a choice, **nothing preselected**; Start stays off until one is picked. Each says whose it is.
- Usable: the business's connected numbers and the person's own. LUME AI also offers the number of whoever it speaks
  as (my call: it speaks as them, so their own number is theirs to send from; never anyone else's).
- No number (or Reply from LUME off): no question; the focus run opens WhatsApp as before, and never sends from a
  number the person didn't choose (`number_asked` marks every run since; older runs keep their old way).
- The run keeps it: every template goes from it, and so does a focus run's message; the run's screen says
  "From +91 …". LUME AI's replies inside a conversation go from the number the lead wrote to (my call, review
  2026-11-27: WhatsApp ties each conversation to one number; a run's own conversations start from its template, so
  they're on its number unless the lead writes to another one).
- Templates: only those approved on that number's WhatsApp account.
- "You can text them directly" only when the lead wrote to **that** number in the last 24 hours.
- A number gone while the run is open: its leads open WhatsApp with why ("+91 … isn't connected any more.").
- LUME AI: a number WhatsApp rated yellow or red can't be picked (as today), said beside it.

## Seeing which number reached whom

- Leads → More filters → **Messaged from** → a number: leads that number sent a WhatsApp message to (from LUME, LUME
  AI or the phone, not one that failed). The chip: "Messaged from +91 …".
- A lead's WhatsApp chat, when the business has more than one number: each message's time line says "from +91 …"
  (sent) or "to +91 …" (received).
- LUME AI's runs list and each run show the number; the focus run's header says "From +91 …".

## Non-goals

No number column, no automatic tags, no remembered last choice.

## Approaches considered

Remembering the last pick (fewer taps, but a run could start on a number nobody chose this time: against "ask");
a number column on the list (clutter, repeats the filter). Chosen: ask every time with 2+, a filter, small labels.
